# Karaoke Platform 0.8.0

This release incorporates major backend search rework, sentiment-aware ranking, automated documentation audit pipelines, and fixes for YouTube Music and saved playlist management.

## Search and vector backend rework

- **Sentiment-Aware Search Ranking**: Introduced sentiment search scoring and benchmarks in `karaoke.search` and `karaoke.librarysearch` to improve query relevance for mood-based searches.
- **Vector Search & Embeddings**: Enhanced vector index management (`vector_index.py`, `clap_vector.py`) for CLAP audio embeddings and hybrid vector query evaluation.
- **Artist Classification & Radio Pipeline**: Added automated artist genre/vibe classification (`artist_classifier.py`) and dynamic radio session pipeline generation (`radio_pipeline.py`).
- **Database Scalability Benchmarking**: Added SQLite vs. PostgreSQL benchmark utilities and migration scripts (`bench_sqlite_vs_postgres.py`, `migrate_sqlite_to_postgres.py`).

## Playlist bug fixes and queue management

- **YouTube Music Playlist Sync & Detection**: Fixed playlist detection edge cases, URL parsing, and saved playlist state synchronization in `ytmusic_playlist.py`.
- **Local Cache & Gap Filling**: Improved local cache synchronization and added gap-filling scripts (`fill_local_gaps.py`) for local collection integrity.
- **Stage View & Queue Suggestions**: Refined stage view UI components (`stage_view.py`) and queue suggestion algorithms (`queue_suggest.py`).

## Documentation & Automation

- **Documentation Maintainer Runbook & Auditor**: Created `scripts/doc_sync.py` and integrated automated docs audit and synchronization into CI (`docs.yml`).
- **Chromecast Dual Playback Plan**: Added detailed architectural plan for two-part experience and Chromecast dual-device playback.

## Verification

- Automated docs audit (`python scripts/doc_sync.py --check`) passed cleanly.
- MkDocs strict build (`mkdocs build --strict`) succeeded with zero errors or broken links.
